01 / Agentic AI Platform

RiskIQ

RiskIQ is a portfolio platform designed for analysts and reviewers who need traceable AI-assisted investigation, rather than free-form chatbot answers. It coordinates specialist workflows and makes evidence and approval status visible in an operations console.

PythonFastAPILangGraph DeepAgentsCogneeReact TypeScriptSQLite

Problem and intended users

Risk, fraud, and model-governance teams often need a repeatable chain from incoming records through validation, investigation, explanation, and an accountable human decision. A text response alone does not capture that process.

Architecture and workflow

React/TypeScript presents investigations, reports, traces, and approval steps. FastAPI validates requests using Pydantic, then LangGraph and DeepAgents coordinate task-specific agents. SQLite persists workflow and case state; Cognee supports contextual memory from prior work.

Engineering decisions and boundaries

  • Separate specialist responsibilities for batch control, feature analysis, fraud and anomaly investigation, forecast explanation, model validation, case workflows, communications, and reporting.
  • Use explicit workflow state and structured outputs for evidence, risk rationale, root-cause summaries, and reviewable decisions.
  • Include human-in-the-loop review, revision, approval, and rejection instead of allowing every agent result to become an automatic action.
  • Persist application state in SQLite while keeping longer-lived contextual memory in Cognee; expose traces and audit context through the console.
  • Project scope: engineering and workflow demonstrations, not a claim of independently validated production fraud-detection performance.

02 / Cloud-Native Full Stack

Virtual Asset Management

A full-stack investment application built around the everyday flow of a portfolio: receive market updates, record holdings and transactions, serve analytics, and answer portfolio-specific questions. The Spring Boot backend connects these features to a React frontend.

JavaSpring Boot 3React AWSPostgreSQLAurora GeminiAWS CDK

Backend and responsibilities

A Spring Boot 3 modular monolith exposes approximately 70 REST endpoints in roughly 18 controller groups for authentication, portfolios, holdings, transactions, market data, analytics, AI, and administration. Spring Data JPA and Flyway manage relational persistence and schema evolution.

Market data and AI integration

Scheduled jobs consume Finnhub, CoinGecko, and Yahoo Finance feeds across four asset types; caching and time-series records support analysis. The Gemini advisor receives structured JSON portfolio context to generate reports and answer questions grounded in the user’s holdings.

Infrastructure, interface, and tradeoffs

  • React, TypeScript, Vite, and Recharts support dashboards for holdings, movements, and portfolio analytics.
  • AWS CDK defines infrastructure using API Gateway, Lambda, ECS Fargate, Aurora, Cognito, KMS, an Application Load Balancer, and Route 53.
  • Spring Security and OAuth2/Cognito handle authentication; the API remains responsible for server-side authorization and business rules.
  • A modular monolith keeps domain logic together while separating controllers and services. Market-feed schedules, failures, and caching require attention to freshness and consistency.
  • Scope and results: implemented application architecture and portfolio workflows; no public user adoption or performance benchmark is claimed.
