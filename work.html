01 / Agentic AI Platform

RiskIQ

I built RiskIQ to explore how AI agents could support risk analysts. Instead of relying on a single chat response, the application assigns specific tasks to agents and shows the evidence, workflow progress, and human review decisions in one interface.

PythonFastAPILangGraph DeepAgentsCogneeReact TypeScriptSQLite

Why I built it

A fraud investigation may involve checking data, looking for unusual patterns, reviewing evidence, and deciding what to do next. I wanted to model that sequence so each part could be tracked and reviewed by a person.

How it works

The React and TypeScript interface displays investigations, reports, execution traces, and approval steps. FastAPI handles requests and uses Pydantic for validation. LangGraph and DeepAgents coordinate the agents, SQLite stores case and workflow information, and Cognee keeps context that can be reused in later investigations.

What I focused on

  • I separated tasks across agents for batch control, feature analysis, fraud and anomaly investigation, forecasting, model validation, case management, communications, and reporting.
  • I used workflow state and structured outputs to keep evidence, risk explanations, root-cause summaries, and review decisions organized.
  • I added review steps so people can revise, approve, or reject agent results before they lead to further action.
  • SQLite stores application state, while Cognee stores context from earlier work. The console lets users inspect traces and decision history.
  • This is an engineering project that demonstrates workflows and system design. I have not independently validated it as a production fraud-detection system.

02 / Cloud-Native Full Stack

Virtual Asset Management

I built this application to manage a virtual investment portfolio. It brings together market prices, holdings, transactions, and analytics, with a Gemini-powered assistant that can answer questions using portfolio data.

JavaSpring Boot 3React AWSPostgreSQLAurora GeminiAWS CDK

Backend and APIs

I organized the Spring Boot 3 backend as a modular monolith with approximately 70 REST endpoints across roughly 18 controller groups. They handle authentication, portfolios, holdings, transactions, market data, analytics, AI features, and administration. I used Spring Data JPA for database access and Flyway to manage schema changes.

Market data and Gemini

Scheduled jobs fetch market data from Finnhub, CoinGecko, and Yahoo Finance across four asset types. I used caching and time-series records to support portfolio analysis. For the AI assistant, I pass structured portfolio information to Gemini so its reports and answers refer to the user’s holdings.

Frontend and infrastructure

  • I used React, TypeScript, Vite, and Recharts to build dashboards for holdings and portfolio activity.
  • I defined AWS infrastructure with CDK, including API Gateway, Lambda, ECS Fargate, Aurora, Cognito, KMS, an Application Load Balancer, and Route 53.
  • I used Spring Security with OAuth2 and Cognito for authentication, while keeping business rules and authorization checks in the backend.
  • I chose a modular monolith to keep related backend logic together while separating controllers and services. Market-data updates also made me think about cache freshness and failed requests.
  • The project demonstrates portfolio workflows and application architecture. I’m not claiming measured performance or public adoption figures.
