01 / Agentic AI Platform

RiskIQ

A multi-agent operations platform for risk, fraud, forecasting, and model-governance workflows. The design replaces generic chatbot interaction with guided, auditable flows and explicit human review.

PythonFastAPILangGraph DeepAgentsCogneeReact TypeScriptSQLite

Problem

Risk operations need structured analysis, traceability, workflow state, and human approval rather than unbounded conversational responses.

Solution

Specialist agents coordinate investigation, root-cause analysis, forecast explanation, model validation, communication, and reporting while persisting state and memory.

Engineering focus

  • FastAPI backend with Pydantic-typed schemas and SQLite-backed workflow state.
  • Human-in-the-loop review, revision, approval, and rejection paths.
  • Cognee-based memory for prior decisions, reusable guidance, investigation patterns, and case history.
  • React/TypeScript console for traces, approval states, memory views, logs, and reporting.

Virtual Asset Management

A financial platform that combines a large Spring Boot API, scheduled market-data ingestion, relational persistence, AWS infrastructure, a React analytics experience, and a Gemini-powered financial advisor.

JavaSpring Boot 3React AWSPostgreSQLAurora GeminiAWS CDK

System scope

Approximately 70 REST endpoints across about 18 controller groups for authentication, portfolios, holdings, transactions, market data, analytics, AI, and administrative workflows.

Data + AI

Scheduled ingestion integrates Finnhub, CoinGecko, and Yahoo Finance with caching and time-series persistence, while Gemini consumes structured portfolio context for grounded reports and questions.

Cloud + security

  • Spring Security and Cognito/OAuth2 protect user-facing workflows.
  • React, TypeScript, Vite, and Recharts provide portfolio tracking and analytics.
